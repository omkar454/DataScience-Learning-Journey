## 📚 Detailed Journey Breakdown

### 🐍 Phase 1: Python Core & Software Engineering
- **Fundamentals**: Variables, control structures, data collections, modularization.
- **Advanced Python**: OOP principles, decorators, generators, memory management, logging, multi-threading/processing.
- **Backend & Tooling**: Web development with **Flask**, database operations (SQL), **Docker** containerization, and **Git/GitHub** version control.

### 📊 Phase 2: Statistics & Exploratory Data Analysis
- **Descriptive & Inferential Statistics**: Normal/Z-Distribution, Student’s t-Distribution, Chi-Square Testing, F-Distribution.
- **EDA & Feature Engineering**: Handling missing values, outlier treatment, feature encoding, scaling, and correlation analysis.

### 🤖 Phase 3: Machine Learning & NLP
- **Supervised Learning**: Linear/Logistic Regression, Decision Trees, Random Forests, XGBoost, SVMs.
- **Unsupervised Learning**: K-Means Clustering, PCA, Hierarchical Clustering.
- **NLP Foundations**: Tokenization, Stopwords, Stemming/Lemmatization, TF-IDF, Bag of Words.

### 🧠 Phase 4: Deep Learning (Current Stage 🎯)
- **Neural Networks (ANN)**: Perceptrons, Activation Functions (ReLU, Softmax), Backpropagation, Gradient Descent, Loss Functions.
- **Sequence Models & RNNs**: Simple RNNs, LSTMs, GRUs, Word Embeddings (Word2Vec, GloVe).
- **Computer Vision (CNN)**: Convolutional Layers, Pooling, Transfer Learning (ResNet, VGG).
- **Frameworks**: Hands-on development using **Keras**, **TensorFlow**, and **PyTorch**.

## 🏃 How to Run Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/omkar454/DataScience-Learning-Journey.git
   cd DataScience-Learning-Journey
   ```

2. **Create & Activate Virtual Environment**:
   ```bash
   python -m venv DL-venv
   # Windows:
   DL-venv\Scripts\activate
   # Linux/macOS:
   source DL-venv/bin/activate
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
